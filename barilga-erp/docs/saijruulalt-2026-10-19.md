# Сайжруулалтын тэмдэглэл — 2026-10-19

Энэ удаад хийсэн өөрчлөлтүүд, хаана байгаа, яаж хэрэглэх вэ. Эрхийн дэлгэрэнгүйг [erh-ba-uureg.md](erh-ba-uureg.md)-ээс үзнэ.

## 1. Цалин

| Өмнө нь | Одоо |
|---|---|
| Үндсэн цалинг өөрчлөхөд **олгоогүй өмнөх сарууд ч** шинэ дүнгээр дахин бодогддог байсан (алдаа). | Цалин **«Хэдэн сараас»** гэж сонгосон сараас эхэлж хүчинтэй. Өмнөх сарууд хуучин дүнгээрээ үлдэнэ. |
| Цалинг `prompt` цонхоор оруулдаг, түүх харагддаггүй. | «Үндсэн цалин оруулах» цонх: дүн, хэдэн сараас, шалтгаан. Тухайн хүний **цалингийн түүх** (хэдэн сараас, хэд, хэн, яагаад) харагдана. |
| Ерөнхий менежер **өөрийн** цалинг өөрөө нэмж чаддаг байсан. | Өөрийн цалинг зөвхөн админ (эзэн) өөрчилнө. Ерөнхий менежер, админы цалинг зөвхөн админ тогтооно. |
| Хоосон хүсэлт ирэхэд цалин арчигддаг байсан. | Дүнг заавал илгээнэ; «цалингүй» гэдгийг тусад нь сонгоно. |
| Олгосон сарын цалинг «тогтоох» оролдлого чимээгүй өнгөрдөг байсан. | Олгосон сард шинэ цалин тогтоохгүй — дараагийн сараас л. |
| Сард ажилд ороогүй хүмүүс (хожим бүртгэгдсэн) өмнөх сарын цалинд гардаг байсан. | Тухайн сард байсан хүмүүс л гарна. |
| Ерөнхий менежер өөртөө урамшуулал бичиж чаддаг байсан. | Өөртөө урамшуулал/суутгалыг зөвхөн админ бичнэ. |

Өмнө тогтоосон бүх үндсэн цалин хэвээрээ (бүх сард хүчинтэй) шилжсэн.

## 2. Ирц (цаг бүртгэл)

- **Мартсан «Явсан»:** өмнө нь өчигдөр «явсан» дараагүй хүнийг өнөөдөр «ирсэн» гэж бүртгэх боломжгүй байсан. Одоо өмнөх өдөр ажлын цагийн төгсгөлөөр автоматаар хаагдаж, «Гарсан цаг бүртгээгүй» гэж тэмдэглэгдэнэ.
- **Цаг засах:** «Ирц → Сарын ирц» дээр бүртгэл бүрийн «засах» товч — ирсэн/явсан цагийг шалтгаантай засна. Засвар бүр «Засварын түүх»-д үлдэнэ. Цалин олгосон сарыг засахгүй, өөрийн ирцийг засахгүй (админаас бусад).
- **Сарын ирц:** хүн бүрийн ирсэн өдөр / ажлын өдөр, хоцорсон, илүү цаг, нийт цаг, хаагдаагүй бүртгэл.
- **Ажлын цаг тохируулах (админ):** эхлэх, дуусах цаг, хоцролтын хүлцэл (минут), хэдэн цагаас илүү бол илүү цаг. Өмнө нь 09:00–18:00 кодонд бичигдсэн байсан.
- Ирц бүртгэх эрхийг (жишээ нь ахлах кассчинд) админ нэмж өгч болно.

## 3. Бараа бүртгэл — ангилал, хэмжээ, жин

- **Ангилал, жин заавал:** бараа шинээр бүртгэх, засахад ангилал болон жин (кг) заавал. Хүргэлтийн машин, буулгалтын төлбөр жингээс бодогддог тул 0 жинтэй бараа буруу тооцоо өгдөг байсан.
- **Хэмжээ:** урт, өргөн, өндөр (м), эзлэхүүн (м³). Өргөн, өндрийг оруулбал эзлэхүүн автоматаар бодогдоно. Жижиг барааны эзлэхүүн 0 болж бөөрөнхийлөгддөг байсныг 6 оронтой болгосон.
- **Бараа орлого дээр шинэ бараа бүртгэх** үед ангилал, жин, хэмжээ, барааны код оруулдаг болсон (өмнө нь бүгд 0 очдог байсан).
- **«Бүртгэл дутуу (N)»** шүүлтүүр: «Агуулахын үлдэгдэл» дээр ангилал, жин, урт, эзлэхүүн дутуу барааг гаргаж, нэг товшилтоор засах цонх нээнэ.
- Нэгжийг монголоор харуулна (pcs → ш, bag → шуудай, sheet → хуудас, m³ → м³). Шинэ барааны анхдагч нэгж «ш».
- Үнийн жагсаалт хэвлэх, Excel-д ангилал монголоор («Cement» биш «Цемент») гарна; хайлт монгол нэрээр ч олно.
- Давхардсан барааны кодын алдаа монголоор гарна.

## 4. Захиалга

- Захиалгын жагсаалтад **төлбөрийн хэлбэр** (Бэлэн 50,000₮ · Зээл 20,000₮), **«өртэй»**, **«хүлээгдэж буй»** тэмдэг.
- Кассчин, салбар (олон дэлгүүртэй үед) харагдана.
- Хурдан огноо: Өнөөдөр, Өчигдөр, 7 хоног, Энэ сар.
- Харагдаж буй захиалгын нийт дүн, төлөгдөөгүй өр, **Excel** татах.
- «Хэмжээ / ангилал» гэсэн ойлгомжгүй баганыг «Машин» болгосон; машины нэр монголоор (Портер, Өөрөө буулгагч, Манипулятор).

## 5. Хэрэглэгчийн эрх — нэмэх, хасах

- **Хэрэглэгчид → Эрх:** ажилтан бүрт 17 эрхийг албан тушаалын анхдагчаас гадна **нэмж** эсвэл **хасаж** болно (жишээ нь кассчинд буцаалт хийх эрхийг хасах, агуулахын ажилтанд ирц бүртгэх эрх нэмэх).
- Хадгалмагц шууд хүчинтэй, дахин нэвтрэх шаардлагагүй. Цэс, товчнууд эрхийн дагуу харагдана.
- Мөнгө гаргах, цалин тогтоох, цуцлах зэрэг эрсдэлтэй эрхийг өөр албан тушаалд **өгөхгүй, зөвхөн хасна**.
- Админ үргэлж бүх эрхтэй (систем түгжигдэхгүй). Эрхийн өөрчлөлт бүр «Засварын түүх»-д.
- Шинэ албан тушаал (role) нэмэх хоёр арга, засварын эрхийг хязгаарлах шаардлагууд: [erh-ba-uureg.md](erh-ba-uureg.md).

## 6. Үгийн алдаа

Дэлгэц, хэвлэх баримт, серверийн мессеж, туршилтын өгөгдлийн **~130 үгийн алдааг** засав. Жишээ:

- харилцагчийн хянах хуудсанд `PENDING_PAYMENT`, `QPAY — UNPAID` гэж англиар гардаг байсныг «Төлбөр хүлээж буй», «QPay — хүлээгдэж буй» болгосон;
- «бүрд» → «бүрт», «үнэгүй» (= үнэ төлбөргүй) → «үнэ ороогүй», «Карт-ээр» → «картаар»;
- засварын түүхэнд албан тушаал, тооцооны мөрийн төрөл англи кодоор биш монголоор бичигдэнэ;
- онлайн захиалгын хуудасны англи алдааны мессежүүд.

## Шийдвэр хүлээж буй зүйлс

- Их дүнтэй буцаалт, кассаас их мөнгө гаргахад хоёр хүний зөвшөөрөл, үнэ өөрчлөх хязгаар (%) гэх мэт — тоог эзэн шийднэ ([erh-ba-uureg.md](erh-ba-uureg.md), Б хэсэг).
- «Албан тушаалын загвар»-ыг нэг товчоор хэрэглэх (одоо гараар тохируулна).
